# M1-B2 形成开发集

自建公开开发夹具，非真实企业/官方/盲测；复用原 rich demo 数据库seed。
12个跨会话目标覆盖6个新术语、SUM/AVG/COUNT、线上渠道及两个年份/地区；10个控制覆盖字段缺失、同名冲突、未审批、来源更新、撤销、无关问题、显式条件冲突、历史失效、SQL安全、重复提取。

sources.json为实际业务文档原文，结构化口径行是受支持的确定性提取契约。没有声称自由文本提取。没有旧candidate_pool条目或最终答案。

tasks/gold/sources与独立scorer、原SQL scorer/helper/seed已在正式执行前SHA256冻结。Gold仅在最终返回后由评分器读取；形成验证参考和任务分分别统计。A关闭；B离线同合法知识；C实际文档处理→提取→验证→本地审核CLI→持久化→重建Store→独立session消费。状态操作是每组共同的开发场景条件。

n03故意不审批；B也不给该条可信记忆。缺字段/冲突B也不得预置可信条目。n08在目标session先消费合法术语后更改来源再追问，是历史失效控制，不能冒充独立跨会话收益。n10两次处理同一来源应去重。精确指标与原始结果另见实验报告。
