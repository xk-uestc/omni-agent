# 多轮结果比较与上下文续轮

开发目录：D:\ICT8-OmniAgent。此轮是本地开发验收，不是官方测试成绩。

## 实现

- 新增独立 ConversationComparisonAgent：解析引用、核验已执行查询记录和完整快照、对齐指标/单位/分组、计算差值。比较不重新执行 SQL，也不调用模型。
- 默认引用最近两轮，不跳过失败或待澄清轮次。只有明确“最近两次成功的SQL查询”才选择最近成功 SQL。
- 相同物理指标/衍生公式、单位、维度才可比较。数据库文件版本或指标目录变化时要求重新查询。
- 按分组键对应，不按返回排序对应。跨年 YYYY-MM 默认不是同组；明确“按月份对齐”才对应月份。重复月份拒绝隐式合并。
- 缺组/NULL 不当零；基准为零或负数不输出默认变化率。显式排名子集标注范围，不冒充全部数据。
- 比较后支持“把基准换成较晚结果”，保留月份对齐选择；SQLite 会话重建可继续比较，跨会话隔离。
- 首页增加比较示例、基准切换按钮及月份对齐澄清按钮；来源区展示原问题、SQL、参数和各自角色。旧按钮在后续响应到达后失效。

## 已知边界

- 比较快照最多128行、16列、8指标、4维度。超过预算、未知截断或部分预览需缩小范围后重新查询；不读取整个下载产物做无限制比较。
- 数据源版本来自既有文件 generation/schema 指纹，不是全库内容哈希；快照摘要是一致性检查，不是防管理员篡改的安全签名。
- 衍生公式引用目前只支持物理指标依赖；不宣称所有嵌套衍生公式都已支持。
- 任意历史轮次编号、自然语言修改比较中的某一侧条件、统一 SSE 全阶段流以及真实浏览器点击验收尚未完成。
- 第一版 HTTP 脚本误将 JSON 列表与参考 tuple 直接比较，产生三个格式误判；已中断修正，并重新运行最终脚本。误判时实际销售额29584/22992、差值-6592、切换基准后6592均正确，不把脚本格式失败描述成模型错误。
