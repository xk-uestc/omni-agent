# PDF位置重绑定与旧高亮失效

检查发现已有PDF坐标的记录再次映射失败时，原 `pdf_geometry` 可在嵌套候选中残留。映射过程现先清除所有旧PDF位置，再核验新的来源：PDF/页图SHA256格式、正整数页号、像素尺寸、有限矩阵和有效显示矩形。每个观察框独立核验页图来源哈希、stored-pixel坐标类型、四角有限坐标及原图范围；全局绑定正确不能替代单框来源核验。

规则网格、无边框独立候选、文字及裁剪位置统一失效或重新映射。失败不修改调用者原记录，也不会把旧页号/旧多边形带到新结果中。

最终图像坐标/OCR/网格回归73通过、1既有警告。真实渲染的PDF八组旋转/cropbox组合覆盖：成功绑定→再次错误页图/非法页号→原文字和候选裁剪旧位置均清除。另四个独立框反例包括来源哈希不同、NaN、超出原图范围及错误坐标类型，不生成PDF高亮。

PDF绝对坐标、入库及文档清理相关49项另通过、1既有警告；两组共122项，未重跑全项目套件。

这是来源一致性和几何验收，不是OCR语义准确率提升；仍未证明公共无边框PDF、透视/跨页、多级表头和结构化数值入库完成。整体目标保持未完成。
