## 验收规则

1. 代码存在、单测通过、真实 API 验收、独立效果证明分别记录。
2. 合成文件是可复现 Demo 样本，不称为真实企业数据或 OHR-Bench 成绩。
3. 未配置 OCR/模型/向量服务时明确显示能力不可用，不把计划或回退当实际执行。
4. 不能从内部夹具准确率直接换算比赛得分或获奖等级。
5. 全部显式要求有证据后才能标记项目完成。
