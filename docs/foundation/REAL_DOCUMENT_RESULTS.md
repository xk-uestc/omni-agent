## 成本及限制

解析性能沿用此前CPU实验数据：开发原路径+OCR入库约41秒，新结构补充约135秒（并发诊断负载，非独占CPU基准）；基础解析器单页首批3.62–13.85秒，子进程累计峰值约2.45GiB，扩展开发峰值约2.73GiB。隔离环境约MinerU662MiB/Docling1.5GiB，模型缓存各约1.4GiB（含下载分块副本）；权重源实际字节与SHA有独立manifest。本轮复查确认宿主终端可见 NVIDIA A100-SXM4-40GB（40GB，驱动580.178.04），但本执行容器无 `/dev/nvidia*`，已安装 MinerU ONNX Runtime 仅提供 CPU/Azure providers；本轮解析仍实际走CPU，文档生成使用已授权DeepSeek API，不声称本地GPU推理。热查询P50/P95由122.0/159.7ms增至161.7/194.4ms，索引Chunk974→1072；正式顺序成本将在冻结验收补记。
