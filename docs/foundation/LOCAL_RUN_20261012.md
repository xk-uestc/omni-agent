## 模型与凭据

初始任务禁止付费，首次启动使用无模型配置。随后用户明确授权本轮 DeepSeek 最多 **¥5、20次调用**，现已启用。
使用生产 `StructuredResponses` / `ResponsesModelPlanProvider`，接口为 [DeepSeek 官方 Responses API](https://api-docs.deepseek.com/guides/responses_api/)，模型 `deepseek-flash`。

私有配置只从用户提供的 `/home/viva/omni-agent/runtime/private/m1c-model.env` 读取；没有复制或提交真实密钥。
新开发者需在自己的私有文件配置 `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`DEEPSEEK_API_KEY`，文件权限为 `0600`。
运行层转换为 `ICT8_GENERATION_PROVIDER=responses`、`ICT8_PLAN_PROVIDER=responses`、
`ICT8_OPENAI_BASE_URL`、`ICT8_OPENAI_API_KEY`、`ICT8_OPENAI_MODEL`、`ICT8_OPENAI_REASONING=low`。
默认运行不需要密钥。

部署层 `budget_transport.py` 统一限制生成、规划和网页体验调用，账本在
`runtime/local_run_20261012/interactive-model-ledger.json`；重启不重置额度。
保存快照时已用 **7/20 次**，剩余 13 次；后续用户交互会继续计数。
费用保护使用高于当前常见计费的保守预算系数，记录的是费用上界而非供应商实际账单。
单次输入上限 100,000 UTF-8 字节、输出上限 2,000 tokens；达到次数或金额上限后不会继续发起上游请求。
