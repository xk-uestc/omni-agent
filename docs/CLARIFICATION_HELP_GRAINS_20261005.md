## 行为

- 用户输入“什么意思”“怎么选”“选项有什么区别”时，按当前待补条件解释时间范围、粒度、指标或具体字段，不执行SQL、不请求模型猜默认条件。
- 普通SQL澄清区增加“解释一下这些选项”按钮。比较子流程和文档问答不显示此按钮；旧轮次按钮继续受已有会话检查及发送后禁用机制约束。
- “按季度”“按周统计”等简短未提供粒度回复保留原问题、已确认筛选和当前重新解析的选项；不会自动替换为按月。
- “按年和按月”与“按月或者按年”都要求确认一种支持的粒度。完整新查询不进入该短回复恢复分支。
- 修复通用前缀规范化误删“选项”中的“选”，保留“选项有什么区别”的真实语义。
- SQLite会话对象重建后仍可从待澄清状态继续选择按月；本轮不把对象重建说成操作系统进程恢复验收。
