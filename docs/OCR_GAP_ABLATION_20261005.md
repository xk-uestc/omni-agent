# 局部检测：冻结新样本独立消融

结论：主动补查的独立收益在本批真实新图上得到观察，但默认自动触发没有获得收益。尚不足以认定稳定泛化，更不能宣称 SOTA。此次只做评测，没有修改算法或阈值、切换生产服务、Git 提交或推送。

## 样本与公平性

- 固定选择下一段 FUNSD 排序测试图与 CORD-v2 测试行，索引 36～43，各 8 图，共 16 图、190 个作者数字词标注。没有根据 OCR 输出或参考答案筛选图片。
- 图像均为真实公开扫描件／拍摄收据，不造退化图。图像 SHA 与此前实验 manifest 无重合，但公开数据可能进入上游训练。
- 八个算法／推理／评分源码冻结并留快照；图像、源码、评分前半程结果一致性校验通过。三种模式分别 fresh 完整推理，关闭→自动→始终，串行避免 CPU 竞争。
- 关闭检测仍有原双读裁剪复核。新增机制独立恢复与回退使用同次运行的前半程逐词配对；三模式前半程与独立关闭结果在全部 16 图上评分一致。
- 本批没有中文复杂表格，不能据此宣布完成所有困难场景覆盖；这是公开数据子集评测，不是比赛官方成绩。

## 失败与下一轮应优先解决的问题

1. **自动调度漏掉实际有收益的数量场景。** 默认自动模式有计算成本、却没有数字收益。应使用开发集研究数量列／结构完整性信号，并在新样本验证，不能直接把本批验证集改成调参后继续声称盲测。
2. **双读者一致也会错。** `cord-041` 的原 Rapid 正确读取 `48982.68`；原有裁剪复核中两个读者都读成 `48982.66`，被接受后产生一项回退。三模式都存在，新增检测自身回退零不意味着整套融合回退零。相对 Rapid，关闭模式恢复 2／回退 1，主动模式恢复 9／回退 1。
3. **字符读取与金额解析不能混为一谈。** `cord-043` 初始结果已经包含 `Rp165000.00` 等金额，但当前 TOKEN 不支持紧邻数字的 `Rp` 前缀，导致解析无数字、评分不匹配、金额路由误触发。这不是所有金额都没被 OCR 读到。自动分支最终仅复核一处背景候选，Rapid=`N`、Paddle=`X`，正确拒绝，没有增益。应补通用货币解析与路由一致性，在新冻结版本中评测，不能通过改变评分口径美化本轮结果。
4. FUNSD 中包含 `UNIT PRICE` 和正文 `fixed price...` 的页面也触发局部检测，但没有新增专家候选。正文金额词不等于漏失表格字段，路由需要结构证据。

上述问题已归档，本轮不边测边调阈值或替换样本。下一轮先修相关开发反例，再选新的冻结验证集；默认自动模式暂不作为“精度和速度双优”的生产结论。
