# 原 PDF 上下文与完整页索引程序验收

当前工作项目：D:/ICT8-OmniAgent。完整迁移/恢复备份位于 D:/ICT8-Backups；原项目及 E 盘迁移快照不修改。

## 本轮实现

- 从固定 SHA 的原 PDF 重抽唯一命中文本块，恢复同一原生块内被段落/标题切分丢失的身份标签；不信任 `raw_page_text`。
- 仅在独立单位块与唯一金额原生行的上下基线差不超过 2 pt、右侧间隙不超过 3 pt 时附加原样单位。标签、金额由多个 native runs 组成时必须完整重建物理行；金额必须是最右端 run。`m` 不被猜测成 `million`，不能作为已认证计算输入。
- 完整块、必要预测标题或唯一作用域无法在预算内保留时，显式 omission；不沿用丢失范围的旧片段继续生成。
- model evidence 独立公开原生块/行 ID、坐标、源/文本哈希；执行结束再次重抽并比对，anchor 整个 payload 也重新核验。检索摘要不改变。
- 严格网格索引完整覆盖候选 PDF 全部页后才落盘。缓存只保存键，不存答案值；选中页重新提取并核对注册表，再渲染和调用模型。
- 索引绑定原文件 SHA、实际页数、PyMuPDF 版本及索引/表格提取/绑定源码 SHA。1000 页/源、20 MiB/源、60 秒构建/源、16 MiB 索引；缓存 128 MiB/128 条。截断、超时、损坏及不完整覆盖不建立唯一性结论。
- 正文页内 IDF 词项覆盖辅助重排，不使用标题/metadata 证明实体存在。保留标识符硬过滤；页邻居仅用于排名，不自动当成生成证据。
