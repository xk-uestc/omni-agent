# 连续澄清恢复与透视局部识别

## 对话恢复

新增ClarificationContinuationAgent，将待澄清问题的恢复处理与意图规划、SQL执行分开。仅处理明确的未选择回复、非法年月、同时选择两种粒度、当前选项标签重名；不兜底吞掉任意新问题。

- “不知道”“什么意思”会保留原问题、已确认范围和重新生成的选项，说明如何补充。不会默认选择条件、调用模型猜答案或执行SQL。
- 年月输入统一复用有边界的回复规范化；“看2025-13吧”“0000年”等不会丢失原问题。
- 恢复状态仅保存未执行问题，不复制成功SQL、比较快照或来源执行权限。失败轮的查询编号不能被当作成功历史引用。
- SQLite重建后可继续补条件；独立完整问题/reset_context退出旧任务，不跨会话继承。
- 前端展示具体错误说明及“原问题已保留、尚未执行”；引用按钮只对成功执行的SQL显示，部分结果和待澄清轮不再提供误导性快捷引用。

## 透视与局部OCR

透视校正已有明确四角输入、投影正逆矩阵、EXIF/旋转/缩放组合和原图坐标绑定。本轮增加SVG投影分母、跨地平线与奇异矩阵的拒绝验证。尚无自动页边界功能。

公开预算原件第一页面经受控透视退化，旧报告public-perspective-explicit-20261005.json所选金额5/7。诊断发现：窄空白未被考虑；检测器把完整标签或金额切成重叠框；原货币符号部分识别为S。

- 使用真实像素空白尝试分割；完整标签和全部数字仍须与原观察一致。
- 真实货币符号候选优先，防止新增模糊候选挤占原有恢复预算。单次识别回调仍无法强制中止，预算是软时间限制。
- 重叠或多行框不直接拼接；先受预算限制地尝试另一缩放，必要时用单行识别。单行识别的高亮框由裁剪图实际墨迹包络计算，保存crop_scale、crop_sha256、crop_bbox_px及定位依据。
- S仅是局部重识别候选，不替换原文。须在局部OCR真实读出货币符号，并且数字、完整标签匹配；符号冲突、数字不一致、低置信度、缺符号均拒绝。
- 保留每次裁剪观察与拒绝原因，不覆盖原OCR全文，不宣称语义数值已验证。
