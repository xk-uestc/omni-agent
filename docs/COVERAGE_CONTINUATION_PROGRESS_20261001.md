## 实证问题与后续修改

1. 文档→SQL：服务器拒绝指标元数据语义冲突。原报告未保存被拒计划，不能凭旧错误码断言究竟是币种、单位或 missing 策略。新增静态细分错误码，不改变验证条件。
2. SQL→文档：实际 `top_n=1` 且 `limit=1`，可能截断并列冠军，因此完整性守卫正确拒绝。排名数量与安全返回上限仍需分离，不能通过删掉并列检查解决。
3. SQL 追问：历史模型 v2 指标与独立规则 legacy 指标结构不同；单元素 IN 与等号也被原比较视为不同。改为物理指标和过滤语义比较，但 missing/unit/currency/metric filters 不一致继续拒绝。
4. 去重：忽略符号的近似比较会丢失 `-100/+100`、加减公式及区间差异。改为仅空白排版等价，符号、大小写与标点差异保留。繁简转换仅用于检索；SHA 基于实际原文。
5. BM25：原底层固定截到 20 项，外层请求 100 并未生效。现在内部分别提供显式有界候选池；公共默认仍为 20 项。
6. 原生续句：真实 fitz PDF 审查发现短否定残句、独立后继句、小写标题及数字后单位裁剪问题。已增加未知残句状态、fresh 原生字体边界、邻接行单位范围与最近显式条件/单位头保护；冻结实测报告不属于后续修改版本。
