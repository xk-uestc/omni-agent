## 已完成的行为

统一 `/api/v1/omni/query` 与 SSE 入口使用真实模型规划和服务端上下文解析；结构化统计走 SQL，定义/方法/政策走文档，需要数据驱动资料检索时走依赖任务。所有响应有 routing 收据，前端展示路径及原因。

成功 SQL 结果在小型完整结果范围内保存有界快照，绑定执行记录、来源版本及指标目录；精确实体/字段短问可读取原结果。问题必须完全被实体、输出字段和排名语义覆盖，新年份、新指标、另一对象、比较或额外条件不复用旧行。复用路径明确返回 sql=null、execution_status=reused_verified_result，界面不伪造新 SQL 调用。

“华北排名多少”后的“它的销售方法是什么”使用核验过的实体检索 RAG；多对象、并列第一、来源变更要求确认。文档问答后的代词或“那华南的方法呢”可绑定已核验的单份资料；显式新文档或新主题保留原来源选择流程。待补时间回复优先进入原待补任务解析。

跨源检索支持“再检索该地区…”与“根据该地区检索…”；维度名来自真实 schema。先校验用户原 SQL 范围，再核对动态引用、排名第一和全部并列项，并独立重放 SQL 结果。模型规划不合格可使用原有的一次有界修复。扩充 schema 中一个“地区”槽位不再同时加入强、弱两个别名候选；显式字段所属表不被此选择替代。

首页与资料页同时展示联合查询的数据表、引用原文和原件链接，脚本版本已更新。SQL 排名正确、检索成功与资料足以回答分开记录：缺少所查实体对应片段时明确提示不能给出其经验，保留真实中间结果供核对。
