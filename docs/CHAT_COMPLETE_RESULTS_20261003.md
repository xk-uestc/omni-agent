# 主聊天完整结果与查询可视化补齐（2026-10-03）

## 赛题缺口与本轮范围

赛题第3页要求“准确、完整且具备可解释性”的答案，第4页要求可交互 Demo。此前独立 NL2SQL 接口支持显式完整结果，但主聊天的 CrossSourceAgent、流式查询和澄清回填没有传递这一选项，网页只能读取最多100行预览。本轮将既有完整结果能力接入这三条路径，并补齐网页分页。

这是结果完整性与交互的工程改进，不是模型准确率提升报告。默认预览行为保持不变；`/omni/query` 与冻结效果评分器没有改动。原始大型官方数据继续外置，凭据和运行目录不进入 Git。

## 已完成

- 页面新增“获取完整结果”；普通请求、SSE、澄清回填均传递 `complete_results=true`。
- 完整读取结束后明确报告完整行数与当前预览行数；触及资源预算时标记部分结果，不冒充完整答案。
- 使用原查询的完整结果产物分页，每页100行；检查查询、来源摘要、列顺序、总行数与页范围，分页不重新执行 SQL。数据源发生变化时返回409并停止读取。
- 保留重复列名、空值、单元格类型与绝对行号；支持下载当前页 JSON，未实现一键全量导出。
- 图表只展示初始预览的前20行；点击后续页的行会取消旧图选中并提示不在图中，不生成假图表。查询步骤明确区分预览上限、完整结果和业务 Top-N。
- 将前几轮已完成的字段 SVG、问题词语/SQL/字段联动、查询步骤导航、表图联动及响应式样式一起纳入 Git。回答继续采用文本与横线分隔。
