# 原件模型输入压缩与独立验收（Round28）

## 实现

`native_row_registry.model_registries/model_rows`只投影模型不需要的重复定位结构：省略页成员重复文本、字段bbox和重复行摘要哈希。保留每份候选来源、源SHA、全部候选页完整文本及页SHA、行顺序、行ID、链/页编号、整行文本、每列表头/列号/原始字段/数值标记及限定符。未做摘要、截断、Top-N或证据筛选，既有来源/256行/90k注册表预算未增加。

原始registry仍用于服务器筛选、数值比较、来源重放、完整收据和前端字段SVG；引用坐标不从压缩输入重建，不增加模型事实权威。源完整性与所有独立审核条件维持；模型输入中的语义身份/全表闭合/计算许可标记仍为false。
