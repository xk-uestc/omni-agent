## 源码与本地合同

- 日期 `_at/_on` 候选仍需执行快照探针。ISO 可解析不等于文本时间顺序；混合 T／空格经整列 SQLite 可解析验证后仅声明原生 JULIANDAY 比较契约，不推断时区、epoch 单位或更高时间精度。
- 主键非空性按实际 SQLite rowid alias 元数据确定，`TEXT/INT/INTEGER PRIMARY KEY DESC/复合主键`不得一概标成非空。
- 分组总体沿用明确的前阶段关系，NULL 分组和无记录实体不能被悄悄删除或补零。真实执行及独立语义审核仍保留。

- 百分比保留精确有理数，支持明确请求的 0～6 位小数并标明舍入。增长率、百分点、未知/冲突精度、跨表/单位/期间操作数继续拒绝。
