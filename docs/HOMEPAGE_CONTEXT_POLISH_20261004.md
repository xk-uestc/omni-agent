# 首页多轮澄清与上下文打磨

本轮只针对对话链路，不代表赛题全部完成。开发根目录为 D:\ICT8-OmniAgent。

## 已完成

- 首页问数与文档问答统一调用 `/api/v1/omni/query`，共用 session_id；关闭上下文会明确 reset_context，新对话使用新 session_id。旧查询 API 保留兼容。
- 连续澄清用服务端 effective_question 作为待补问题，不再用上一次选项标签丢失已确认的年份或字段。
- 年份、月份与时间范围选项提供输入框，selected_time 交后端校验；后续成功响应禁用历史澄清控件。失败时保留可重选入口，后端仍拒绝过期选择。
- 直接输入精确年份/月或“按月”“按年”可以补全当前待澄清问题；只接受服务端当前提供的选项，无效日期和复合条件不会被视为已确认时间选择。
- 展示本轮实际完整查询问题及明确引用的问题；不把 context_turns 当作继承条件的证明。回答采用横线分隔，无新增圆角回答卡片。
- 真实模型曾将“销售额趋势”降级为全时间销售总额。本轮为已识别的缺时间范围/粒度/比较时间澄清建立执行前检查，缺项时不进入模型 SQL 执行。
- 澄清选项验证改用无模型、无执行的 extract_required_intent，避免再次模型规划造成选项漂移或验证阶段执行查询。
- 统一接口转交 complete_results 选项到单源 SQL 查询及澄清后查询。
