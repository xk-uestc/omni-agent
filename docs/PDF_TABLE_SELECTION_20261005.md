# PDF逐页表头选择与来源绑定

本轮将扫描表格结构整理接入PDF预览，保持独立Agent边界，不把结构观察当作数值语义核验。

## 实现

新增`PdfTablePreviewAgent`，由`POST /api/v1/documents/chunks-preview`调用。请求增加可选`pdf_table_headers`列表，每项明确`page_no`（1起始）、`table_index`（0起始）、`header_rows`（0～5）。一次最多8个表格、4个不同页面；重复指定同一页同一表格、越界页码与选择拒绝。非PDF不能携带此选项。

结果在独立`table_structures`列表输出，不把OCR表头猜测写入原有文字分块或资料库。原生PDF额外OCR用户指定页，保留已有文字提取结果；扫描PDF复用解析过程中已经成功且PDF SHA/页码匹配的OCR metadata。对同页不同表格共用同一识别结果。需要新增识别时使用请求指定的语言，不强制英文。

结构Agent继续负责表头路径、合并范围和原图坐标；PDF Agent为其绑定原PDF SHA、页码、PDF用户空间和未旋转空间坐标。正文锚点和标题引用都须有匹配的、可高亮的PDF坐标，否则返回不可用。原有单次PDF解析页数/OCR预算保持；4页限制约束新增表格预览，不代表基础解析只处理这4页。

OCR未配置、未接受、失败、网格不存在或坐标不匹配均明确返回不可用；不生成推测金额。`native_text_replaced=false`表示表格预览Agent没有覆盖原生文字，不表示扫描PDF本身没有使用OCR。

## 网页

文档工作台扫描区支持上传PDF，提供PDF页码、表格序号和表头行数。PDF必须明确填写表头行数，没有表头填0。结果显示指定页表格，保留真实rowspan/colspan、空白和OCR原文；单元格提示提供原PDF坐标，详情保留完整SHA/页码/来源信息。网页目前一次指定一页一表；API可同时指定多页多表。图片原入口继续兼容。

知识页脚本更新`20261005-pdf-table-structure-1`，页面和脚本HTTP200，knowledge.js语法检查通过。尚未新增PDF SVG点击高亮，也没有真实浏览器点击验收。
