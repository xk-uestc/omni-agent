## 实现

- `date_profile.py`：日期问题可按明确提及的物理表补充相关日期列；结构校验后的候选 SQL 再请求实际日期依赖列探针。候选依赖从受限、已限定的只读 AST 中提取，不执行候选 SQL。整列验证和时间/列数/SQLite步骤预算仍有效；探针未知不会变成日期格式断言。
- `question_roles.py`：为“各/每个物理字段合计”等粒度补充局部角色识别；只有唯一可核验字段来源才绑定。同名字段仍保留歧义。
- `schema.py`：局部“不按某日期过滤”不再被当作正向过滤字段；数值否定仍保留。
- `complex_query.py`：显式物理字段按各组聚合进入已有结构校验及独立审核通道。
- `engine.py`：安全失败带固定阶段和原因码，不复制SQL、模型正文或底层数据库错误文本；SQL执行、范围校验和完整结果交付阶段可追踪。
- `run_cross_schema_round5.py`：完整隔离回放记录上述安全诊断元数据。
