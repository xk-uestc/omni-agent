# 主问答自动页级视觉表格路由

## 已实现链路

主 KnowledgeStore.answer 先检索候选PDF资料，完整检查候选资料内的页面网格；原问题只有唯一完整行列键且无未绑定条件时，才用原页图调用指定模型选择单元格，再以服务器字面值与独立OCR核对作答。返回主问答兼容的citation、trace、来源SHA、页码、格ID和bbox；Omni document分支复用这条主路径。

未指定来源时，唯一性仅限检索选中的PDF资料，不是全库唯一。显式document_id会在文本检索前过滤来源，不从全库截断后猜选文件；指定page_no必须同时指定PDF资料，文本检索和视觉核验均限定该页。

本轮实现最多4份候选资料、12页、总源文件40MiB。候选超预算、同键跨页/跨文件重复、额外条件、模型失败或OCR不一致不转回文本模型猜数值，而返回incomplete及范围说明。超预算可选择文件及页码重试。检查后重核所有候选文件版本，防止未获选文件换版破坏唯一性依据。

共享进程级视觉工作限流覆盖直接页图、直接问数和主自动路由；忙时HTTP429。当前不是跨进程共享队列。

纯问题绑定重构还修复一项label边界漏洞：合法独立West存在时，额外showWest不能被删除成show而放行。

## 真实验证

- 真实主知识HTTP，不带document_id/page_no，自动定位合成网格，返回West / 2025 Units: 6635，三格本地OCR一致。1次gpt-6-luna/medium completed，1038 tokens，报告 `VISUAL_ROUTE_HTTP_20261001T084531658825Z.json`。
- 实际网页从文档问答表单发送同题一次，显示答案、来源原件及页图按钮；gpt-6-luna/medium，1015 tokens，报告 `VISUAL_ROUTE_BROWSER_20261001.json` 与两张截图。
- 本轮以上两次真实模型请求合计2053 tokens。是已曝光的冻结合成开发样本，不能作为官方或独立未知题准确率。
- 样本原PDF已加入samples与manifest，默认新目录启动也能重建该示例，不依赖本机旧runtime。此时16份样本、6种格式、301593字节。
- 最后完整本地回归1168 passed、0 failed、1条Starlette弃用告警，53.65秒。新文件/页码选择及两种主路由同样受测，但测试替身不代表模型准确率。

## 未完成边界

纯扫描/图片页没有文字或OCR检索命中时，当前不能自动发现，需明确选择资料；扫描表结构仍未支持。有线网格仅支持单层内部表头、首列行键；无边框/合并/多层/跨页表格及图表不完整。精确查值仍要求原样完整标签，不宣称一般自然语言Schema Linking。

无PDF候选、无完整原生网格键或未配置视觉模型时，正常文本问答仍可使用其原有证据验证链路，trace明确标明视觉未接管；不能将文本回答称为已验证视觉表格答案。大PDF预算澄清会限制普通PDF问答，下一步须用完整页级索引与选页证据改善此边界，不能简单放宽唯一性守卫。

本轮没有重跑官方OHR或44题全量真实验收。最新官方OHR冻结12题仍EM0/12，不从本轮两个成功演示推断官方提升或全赛题完成。
