# 无EXIF扫描件的方向、倾斜告警与校正预览

## 原始缺口与实际结果

旧程序可识别旋转图片的一部分文字，但方向质量探针仅查看EXIF。没有EXIF的颠倒、侧转、倾斜未生成方向告警，入库后未要求复核；颠倒后的文字行还沿用倒序。

首次冻结的10项新增契约0/10，见ORIENTATION_FIRST_RUN.json。这不是文字识别准确率0/10：同一报告保留了正确的识别原文，失败的是方向检测、告警和入库复核契约。

修复后扩展13/13，见ORIENTATION_REPORT.json：

- 正向、逆时针90°、180°、270°、±7°倾斜、180°+7°复合旋转。
- 空白图与无文字插图不猜测方向。
- 图片、扫描PDF和Word内嵌扫描图入库保留方向依据及原文件，标记review_required。
- 局部文字正向识别后按校正坐标排序；校正预览不覆盖原文件。

另在真实浏览器的knowledge.html上传颠倒样本、检测180°、点击生成预览并确认正向图片。发现旧image-enhance请求模型只允许±45°；现支持有界±360°，并用6色像素金标验证90°/180°/270°实际像素与尺寸，±361°拒绝。

完整本地回归563项通过；实际OCR扰动维持原图8/10→增强10/10，问数扰动5/5。Dense混合验收QA11/11、SQL12/12、跨源5/5。以上均为本地开发验收，不是官方未知题成绩。

## 程序机制与边界

RapidOCR同一次推理提供检测四边形及0/180局部方向分类；适配器在其最终过滤前收集观测，不额外运行一个模型，不增加外部API。方向推断结合长边轴向与RapidOCR对高窄crop逆时针90°旋转的约定，避免把侧转误报为颠倒。

至少两条可靠文字；方向分类≥0.90、文字识别≥0.75、文字至少4字符、框长宽比≥2；最多±15°残余倾斜，方向票≥80%，角度中位绝对偏差≤2°。阈值属于未独立校准的开发启发式，不是页面准确率保证。混排、少量文字、非可靠图形和大角度斜排返回undetermined，没有自动全页旋转。

识别流程仅对文本区域做透视/方向校正，不写原文件。正向行顺序是几何排序，不是多栏/表格布局模型。坐标metadata声明ocr_executor_input及尺寸/SHA；图片增强后坐标不能冒充原图坐标。原始输入SHA单独保留，EXIF校正单独告警。API返回input_quality、orientation、reading_order、coordinate_frame及实际尝试记录。

网页展示方向估计和文字，用户确认后生成单独的图片预览；原文件、知识库和SHA不被替换。源文件保留与告警沿图片/PDF/Word路径传播。OCR方向分类置信度不是文字准确率，也不证明内容事实为真。
