## 冻结评测期间独立审查发现的待修复项

1. **未知目标业务限定可能遗漏。** 例如“2025年南湾已批准每笔核算额，计算公式用文档，费用金额合计和包裹ID记录计数从数据库取值。”正常工具图可返回成功，但“已批准”未进入范围。仅 SQL 来源范围验证不证明整个目标口径完整。下一修复应完整验证目标名称及剩余业务限定，不能只扩充有限黑名单。
2. **完整新 SQL 问题的语气词可能触发融合继承。** 成功融合后“2024年华北地区销售额呢”被误作短追问而澄清。应先由服务器识别完整独立查询且无继承引用，再选择独立上下文，不能依赖模型改写。
3. **SQL→检索指代被误当作遗漏 SQL 维度。** “先从数据库查2025年销售额排名第一的地区，再根据该地区检索冠军团队的方法，保留来源。”上游 rank/top_n=1 的意图完整，但外部范围检查拒绝下游“该地区”。应验证该维度是唯一上游的真实输出、下游实际引用及原文检索目标，再将这个特定依赖范围划归文档来源；不能直接忽略所有包含“检索”的句子。
