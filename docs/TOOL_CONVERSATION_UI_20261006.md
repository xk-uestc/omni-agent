# 工具调用式对话界面验收

2026-10-06：主聊天及资料库对话使用本地React/ReactDOM组件展示真实工具调用。每条处理说明及调用左侧有SVG图标，调用行可展开输入/反馈，完成、澄清、错误与停止分别显示。移除原四阶段01—04占位轨道；最终业务回答直接输出文本，SQL、参数、字段SVG和结果图保留于可展开详情。

新增统一对话SSE接口`POST /api/v1/omni/query/stream`。围绕实际上下文处理、规划、SQL、检索、文档回答及跨源工具发送真实事件，最后返回原查询完整snapshot，不额外写入会话。融合子任务只转发已有真实完成/失败事件；部分历史查询修改内部尚无细粒度开始事件，不能假造已执行。取消网页请求不保证后台查询已经取消，超时提示保留此边界。

前端按call_id合并开始与完成事件，并消除最终结果重复工具。未知状态不默认成功，未执行计划不展示为工具成功；确认来源的SQL结果才补充数据库读取记录。可视化记录在本地组件实际产生图形之后生成，明确只用本次查询预览。数据库写入事件必须有明确executed=true和成功结果；当前产品查询仍只读，修改查询条件不当作修改数据库内容。

React 18.3.1发行文件本地附带MIT许可，无需运行时访问CDN。工具面板支持语法高亮、复制、输入/反馈页签、键盘展开、深浅色及移动宽度。最终回答及来源说明不使用圆角卡片。输入区域用flex底栏，避免遮住最后一段答案。React组件随切换会话和退出页面卸载。
