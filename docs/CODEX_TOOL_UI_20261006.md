# 工具调用式前端验收

正式页面：http://127.0.0.1:8030/ 。

使用本地 React 18.3.1 组件展示实际执行事件，每条说明及工具调用左侧都有 SVG 图标。固定四步占位栏不再展示。SQL 工具反馈支持输入/输出切换和语法高亮；字段 SVG 与数据关系放在 NL2SQL 调用详情内；本地图表放在 visualization.build 的工具反馈内。回答正文直接呈现文本及结果表格。

本轮进一步将原有 SVG 与图表组件挂载到 React 工具详情中，保留字段定位、选择及事件监听，并修正复制按钮以复制当前所选标签页。

运行 `tools/verify_tool_timeline_browser.js`，真实隔离 HTTP 服务 + Edge，14 项通过，浏览器运行错误为 0。验证涉及实际 SSE、SQL 执行结果、图标、彩色代码、字段 SVG、图表归属、澄清、连接中断、会话清理、深色与手机布局。使用隔离样本数据库，无模型 API 调用，不代表模型准确率验收。

完整报告及截图：`runtime/tool-timeline-browser-428d045a-0096-4a5e-a952-e3bb806e956f/`（本机运行产物，不提交）。两次先前失败报告保留，均为新增嵌套详情后浏览器测试选择器歧义，最终使用具体组件选择器复测通过。

展示原则：修改查询条件不等于修改数据库内容。database.write 只有实际 executed=true 且返回成功才可标为完成；本轮没有新增数据库写入权限或假造写入事件。React 负责工具时间线，原有 SVG、结果及页面组件仍通过保留接口集成，并非将全站重写为 React。
