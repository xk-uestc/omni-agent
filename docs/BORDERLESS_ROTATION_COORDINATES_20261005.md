# 无边框表格的独立候选与原图定位

旋转实测发现：原图文字置信度略高时，OCR最终选择原图文字，导致校正尝试的无边框表格候选丢失。现为无边框候选独立记录完整行比例、观察框数及置信度选择结果，保存候选自己的执行图哈希、变换链、原图位置和尝试号；不将候选框冒充为最终文字尝试的框。

局部补识别框及其裁剪范围分别映回原图。PDF坐标绑定同时处理独立无边框候选，保留PDF哈希/页号；八种真实PDF渲染几何组合验证候选文字和裁剪多边形一致，错渲染哈希拒绝映射。PDF测试是颜色标记几何夹具，不是公共PDF表格识别成绩。

文档处理元数据保存独立候选；原图SVG组件在没有严格网格时展示无边框候选观察框，标注候选/局部补识别，来源不符不显示高亮。严格网格优先，避免同一位置重复显示。

真实RapidOCR在同一生成的印刷无边框图片原图、90°和5°倾斜三例均返回4行2列，数值1、123456、123456789、42全部正确；三例各恢复一个缺失数值，文字/裁剪框均在原图范围内。失败版本0°通过、90°和5°失败保留 `runtime/borderless-rotations-before-selection-20261005.json`；最终3/3报告 `runtime/borderless-rotations-20261005.json`。

最终受影响回归95通过、1既有警告；增加PDF独立候选绑定后坐标专项46通过；SVG模型4通过，语法检查通过。服务重启加载本轮源码。无浏览器点击和全项目重验，不是公共或官方基准。

整体目标未完成：公共无边框PDF、透视、跨页与多级表头、数值独立核验/结构化入库、复杂任意历史指代仍缺。无边框依旧是候选，不推断缺失空格或表头含义。
