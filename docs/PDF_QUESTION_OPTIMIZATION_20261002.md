# PDF 问答第二轮优化

## 程序变更

- 原文 quote-ID 目录：模型选择原文引用 ID，服务器恢复唯一原文字面 context/scope，减少多行 PDF 证据重抄的失败。答案仍必须为严格原文，且由完整事实支持；原始证据、数值符号边界、独立问题复核及来源快照检查保留。
- 多栏金额表：按重复金额右边界划分独立 panel，恢复缩进总额行。邻接的印刷金额后缀 `m/k/bn` 只约束该金额，绝不传播到没有明确后缀的其他行；币种仍 unknown。Agency 原 PDF 从 0 条增加到 34 条可定位金额事实，这个计数不是准确率。
- 图表算术：模型只选择原生事实 ID 与 lookup/sum/difference/ratio，数值由程序 Fraction 精确计算，再独立复核完整问题、方向与范围。保留跨源核验、fresh manifest 重放、零分母和非终止比值拒绝，不用像素估算数字。
- 跨栏续句：仅在相邻 native 栏的底部到顶部、有完整几何、相同边界样式、无中间块且有明确句尾时连接。保留完整前文、限定及原生字面位置，只附下一栏的第一完整句。版面证据不是语法/同篇文章的形式证明，仍需模型语义校验。
- 前端区分图表原值与程序计算，展示操作数、范围、计算和独立复核记录。

## 验证方式

基线隔离在 Git `4268eb5` 的独立目录中，复制同一公开 dense 资产，只使用现有本地 runtime 配置。所有真实请求仅 `gpt-6-luna`、medium；金标仅用于评分，未传入模型或原件库。

原 12 题、已曝光第二组 9 题与新 8 题都在各组相同问题、相同金标、相同 PDF 库和同一个已核验 store 上进行基线/新版对照。两版均跳过独立 raster OCR 诊断，实际 PDF 原生读取仍执行，既有 native ingest 的 OCR 结果不替换为 GT。对照工具核验 selection、manifest、数据 revision、每题问题与金标、源码起止稳定性；不改写保存的答案或分数。
