# 普通数据库查询减少重复来源规划

用户截图中的等待发生在intent.plan。原统一查询先知识库检索，向模型提供数据库结构和文档预览选择来源，再调用NL2SQL模型生成计划。对于已经完整识别的普通数据库查询，这次来源规划增加一次模型请求及不相关文档导航。

## 改动与边界

`OmniAgent._verified_sql_route`在原上下文处理完成后，仅对完整的简单数据库问题选择sql来源。必须配置原SQL模型规划器，适配器明确支持快捷来源判断；问题同时包含实际指标和可解析时间，真实Schema字段、取值和时间跨度覆盖全部语义。剩余仅允许普通查询、统计、汇总、排名等连接词。不支持的词、未知值、派生指标、同比、版本/文档/解释/目标、文档标题/ID、追问歧义均保持原模型来源规划。已绑定历史及来源的既有处理优先；不会清掉原约束。

该路径只决定来源，原问题完整传入engine.answer；SQL仍由gpt-6-luna/medium生成，独立意图核验、字段合法性、原单位、编译器、只读执行及来源快照保持原流程。规划来源显式记录server_verified_sql_route，不把服务端识别冒充模型调用，未执行的intent.plan/knowledge.search不生成工具成功记录。
