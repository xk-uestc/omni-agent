# 指定两项历史来源的结果比较

本轮将历史引用Agent的纯来源选择共享给比较Agent。选择与执行记录/完整结果快照/来源版本/指标定义/分组对齐校验分开；比较不重新执行SQL，也不调用模型猜测所指对象。

## 用户能力

- “比较倒数第三次和倒数第一次SQL查询”：只计当前保留窗口里的SQL尝试，文档插话不参与计数。
- “比较SQL查询“2024年华东销售额”和“2025年华南销售额””：精确匹配原问题或实际完整问题，不用模糊子串；重复匹配要求指定倒数位置。
- “比较倒数第二次和倒数第一次成功的SQL查询”：用户明确指定成功记录才跳过失败，普通引用不跳过未成功/待澄清的查询。
- 默认按查询发生先后，以较早查询为基准；短句中先写哪一项不会改变方向。可加“以较晚结果为基准”，后续也可切换基准。
- 新指定的来源优先于上轮比较上下文；随后切基准、按月份对齐或修改一侧继续使用已核验的那两项来源。
- 同一查询重复引用、越界、缺失、语法未支持、来源版本改变、快照损坏、指标不一致等进入明确澄清，绝不改用最近两次结果。

前端来源区标明“选取时的历史窗口第N轮”，不是会话开头绝对编号。原问题、SQL、参数与基准角色仍完整展示。
