# 图像坐标链与独立扫描表格证据

## 本轮实现

1. ImageEnhancer 记录原图尺寸、SHA-256、EXIF方向及实际几何操作。支持 EXIF 1–8（包括镜像）、任意角中心旋转及 expand 补白、整数裁剪、按实际输出尺寸记录缩放比例。
2. 六系数使用行式约定 `x'=a*x+b*y+c; y'=d*x+e*y+f`，坐标为像素边界、左上原点、向右/向下；不混用 PyMuPDF 的系数顺序。
3. OCR框、规则网格单元格及局部恢复裁剪框，在匹配源图/执行输入SHA、尺寸和坐标帧后附加原图四角多边形。原框不改写；落入补白、超出执行帧、退化/非有限/非凸框不取得原图高亮资格。
4. PDF入库把原图多边形继续映射到原PDF用户空间和未旋转页面空间，绑定扫描PDF哈希、页码与渲染哈希。渲染取整补白不能取得PDF高亮资格。
5. 文字与表格结构单独选择候选。保持较好的基线文字，同时保留覆盖较完整的网格尝试；`scanned_table_evidence`携带自己的执行坐标帧、图像变换链及原图/PDF坐标，不把它伪装成文字候选的坐标。
6. 文档页增加扫描件SVG定位预览，切换文字/单元格/两者，点击或键盘选择查看OCR观察值。原图先经默认标准化生成PNG，单独验证预览内容哈希；由原存储像素映到显示帧，处理浏览器EXIF显示造成的方向差异。
