## 下一步的协议改进方向

当前选择规划既要给筛选/投影列，又要逐行逐列重复列举完整匹配清单的字面片段。对直接请求完整字段的问答，这部分可由有界原件编译器确定，容易带来重复规划和漏片段。

可增加显式`whole_fields`与`exact_spans`两种计划协议：前者只允许空片段并从完整匹配清单生成每个原字段，后者继续要求逐项精确唯一绑定；独立审核仍读取所有竞争来源/行，并核对完整行清单、原始问题和最终答案。不能把当前不完整片段静默当成完整字段，也不能采用限制行数或放宽任何审核。需要独立测试、模型实测及新的收据版本后才能采纳。
