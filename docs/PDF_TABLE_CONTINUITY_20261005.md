# PDF跨页表格拼接预览

## 实现

新增独立 `PdfTableContinuityAgent`：对已选择的逐页结构生成相邻页候选，明确用户确认连接后按页序拼接。候选不代表同一业务表已经证明，不自动拼接同列数或同表头的表。

`/api/v1/documents/chunks-preview` 新增 `pdf_table_links`，每项明确 `from_page/from_table/to_page/to_table`。只允许已选择相邻页面，重复、分叉、未选择表格与跳页连接在OCR前返回400。每次最多8表/4页，链接最多7条。

拼接重新检查同PDF哈希、表格完整矩形结构、列数、列序、原页单元格坐标与表头路径。重复表头由各页人工表头选择排除；后续无表头页保留首行数据、沿用首段表头。重复数据行、空白、原页合并锚点和逐页表头坐标保留，不补零、不猜跨页拆断单元格。

结果包含 `rows`（原页号、表格序号、原行号、原单元格）、`segments`（每页范围和表头）、来源SHA及未绑定OCR观察编号。少量未绑定文字不阻止观察结构预览，但 `all_observations_assigned=false` 并显示警告；这不是完整语义表或SQL可用库，`cell_values_verified/ready_for_sql_import`仍为false。无法得到结构或位置时整条链拒绝，不发布部分链。

文档页提供起止页、首段与后续页表头行数，并逐个确认续表关系；结果展示原页号和每格PDF坐标。更换文件/重新预览后迟到响应不更新当前PDF预览。旧单页接口兼容。

## 实测发现及修复

初次真实拆页扫描没有识别出网格，并触发首段不可用时读取`columns`的500。新增不可用首段反例并修复为拒绝。随后定位短表的重复文字竖笔画超过投影阈值，误当列线；列线增加至少连接一段完整横向行边界的检查，允许合并表格局部短线。拆页结构从不可用变为5×2与6×2，原有网格/合并/旋转回归通过。

原失败报告保留：

- `runtime/pdf-continuity-http-7562a504dc34492c8a0db247b9b70ec0.json`（首个负例通过，第二请求500）
- `runtime/pdf-continuity-http-c1c5c07ac0134ad5906226baff75b53e.json`（网格不可用）
- `runtime/pdf-continuity-http-c5359a8e156d40a5898a302deadebb1a.json`（网格恢复，尚因未绑定框拒绝预览）

最终相关后端134 passed、1个既有Starlette/httpx警告；前端上下文/会话/请求/SVG/续表模型60 passed，knowledge语法检查通过。没有项目全量或真实浏览器点击验收。

真实OCR接口验收脚本：`tools/verify_pdf_continuity_http.py`。公开原件为OHR-Bench的`administration/DUDE_a77d8e23b8ff302d04dd6254e4a67159.pdf`，SHA `7386776d1a2bada2f9d8068dec77c79e0ff832d90af6cf2c869f84651065b4bd`。原第1页表格接第2页正文应拒绝；正向将公开第1页预算表受控拆成两页无文字层扫描，含第二页90°旋转变体。保留原页位置、5+6行与源哈希，拼接每格等于逐页原值；两端Personnel/$47,000与TOTAL:/$100,000有金标检查，不代表完整金额准确率或独立数值核验。
