# 多轮澄清输入与请求生命周期

本轮仅修改前端多轮交互，复用现有 Omni 查询和澄清接口，不改变 SQL 规划、历史核验或比较算法。

- 输入框旁显示后端实际待补条件和累计完整问题；时间范围与时间粒度提供不同输入示例，分组字段歧义不再统一显示为“查询条件”。
- “独立提问”仅使下一次普通查询发送 reset_context=true，保持同一 session；成功响应后恢复追问模式。点击按钮本身尚未取消服务端待处理任务。
- 请求发出前立即锁定旧澄清/比较选项。网络失败时不自动恢复旧选项，因为服务端是否已执行无法仅由网络错误判断。
- 新对话终止旧控制器并清空本地提示；旧请求 finally 只有仍持有当前控制器时才可解锁输入，防止旧请求结束影响新请求。
- 保留横线和纯文本布局，动态文本通过 textContent 写入，无新增回答圆角卡片。
