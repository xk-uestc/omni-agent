# 自动页边界、局部裁剪与独立观察保留

## 架构和范围

PageBoundaryDetectionAgent基于实际图像亮度、Lab背景色差、四边对比、内部前景覆盖及轮廓拟合生成候选四角；PerspectiveRectificationAgent执行有界单应变换，保留正逆映射和原图哈希。默认最多三次OCR尝试，不把几何候选或OCR置信度当作语义正确率。

内部表格框不能作为纸张边界。两个面积接近的页面候选保持歧义，不任意选一张。校正失败或较差时保留已有成功文字结果。

本续轮进一步收紧裁切前校验：全部已观察非空文字，包括低置信度文字，都必须有合法有限置信度、四角原图多边形、正确来源哈希和坐标类型，且经可逆EXIF映射落在纸内；缺映射、奇异矩阵、错误来源或纸外观察均拒绝自动裁切。该检查只证明没有裁掉已观察文字，不能证明OCR尚未检测的内容完整。

OcrEvidenceSelectionAgent可以补充其他尝试中位置不重叠的单行独立条目，保持各自执行帧、变换链和来源坐标。相同位置但文字冲突、来源不同、坐标越界、置信度非法、内部重叠、缺执行帧均不合并；最多32个独立条目，不拼接为完整表格，也不提升数值核验状态。前端紫色独立条目层展示实际尝试和补充来源。
