## 实现

- 局部标签/金额布局保留至多16个 `regional_candidates`，不再仅丢弃到一个最大的区域。旧 `rows` 字段保留最大局部区域，不能把它当成全页。
- 标签重复左边缘或右边缘都可构成局部候选；顶部右对齐汇总标签不再因左边缘变化而被拆成孤立行。
- 数字行与标签行都须有明确中心间距；只容许有界、较小的框重叠，不容许重叠同一行伪装成多行。
- 行间未配对的大写标题、跨过数字列的小计文字构成分段证据；不将其补成虚构金额行或已核验表头。这是布局启发式，可能保守漏掉大写续文。
- 每区文字/连续性证据独立映回原图与PDF，重绑定失败清除旧高亮，区域列表类型或预算非法拒绝原图映射。OCR尝试选优计算所有保留区域的观察数。
- 原图SVG按区域分别高亮，不重复显示旧兼容主区域，并明确每个区域的观察编号。
