- 计算与文字混合子问：只允许明确2至4子问、一次有界执行。逐项完成普通回答流程，每项必须有本次新产生的成功模型审计和原件引用；至少一项计算结果重抽原始表格事实并重新计算一致。完整原问题再独立复核，任一失败不得拼成成功答案。
