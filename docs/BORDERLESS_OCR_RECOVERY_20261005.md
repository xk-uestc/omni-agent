# 无边框右对齐表格与局部OCR恢复

原无边框候选只检查文字中心，金额宽度变化大时无法对齐。本轮补充至少三行重复的左/右边缘与全局列间空白检查；列间文字框重叠不作为表格。结果仍为几何候选，不是经独立核验的结构化事实。

缺失列位置在其他完整行的观测边界内进行局部裁剪、两倍放大与真实OCR；最多8次、启动下一调用前检查10秒调度预算，每裁剪最多600万像素。模型返回框按实际缩放与裁剪位置映回执行图坐标，保存裁剪SHA及来源；再运行全表几何检查，只有行列数量不变、候选仍成立且缺失行减少才接受。原全文文本保持不变，无文字响应不填值，失败保留原候选。

## 验证

- 最终OCR、规则网格、坐标、方向及图像质量回归93通过，1既有弃用警告。
- 同一生成的无边框印刷图片真实RapidOCR：首版漏第一行单字符1，报告保留为 `runtime/borderless-scan-real-ocr-first-20261005.json`；局部恢复后4×2全部观测成功，四数值为1、123456、123456789、42。最终报告 `runtime/borderless-scan-real-ocr-20261005.json`。
- 裁剪映回坐标、调用/时间预算、超出框和失败不填值均有反例测试。
- 原有真实合并表格夹具重新执行，检查规则网格不会因新增无边框分支退化。

这是受控生成图片真实OCR，不是公共文档/官方基准。未对真实公共无边框PDF做本轮验收；无边框候选不是严格网格，不自动推断表头、合并格或空值，不自动结构化入库。透视/跨页、多级表头、数字独立复核、杂乱页面多表定位仍需进一步实现。整体目标未完成。
