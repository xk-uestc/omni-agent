# 多轮上下文与低质量文档：本轮交付及未完成边界

## 实现

- `OmniAgent.query` 通过 `ConversationStore.turn` 包围完整的读历史、规划、执行、记忆流程。同一进程同一会话串行，不同会话并发；澄清验证使用同一可重入锁。异常释放锁，最后等待者退出时删除锁登记。内存状态在写入与读取时均隔离，避免调用方修改内部记忆。
- 12轮地区/年份/指标/分组追问覆盖4轮窗口截断、SQLite会话存储重建、独立会话和重置。通过现有澄清解析器复用服务端真实字段候选；字段确认之后允许继续要求缺失日期口径，未经执行的结果不会成为成功历史。
- OCR方向证据可安排下一次图像校正识别，最多3次主图识别，不额外偷加主图调用。使用有限角度、白色填充、原图候选保留、非空结果比较；校正后的框属于执行器输入坐标，未计算原图逆映射时明确不可当作原图框。
- OCR阅读顺序支持保守的双栏正文分隔。短数字网格不触发正文分栏，跨栏标题分段保留。此算法是几何启发式，不保证任意版面。
- OCR四点框形成行列候选；像素中的完整横纵线形成规则扫描表格网格。无法绑定跨列框不猜测。对缺失单元格最多8次局部OCR，10秒为下一次调用的调度预算，不能冒充硬推理超时。保留裁切哈希、置信度、空单元格、原始符号与未绑定框。
- 候选表格及单元格OCR观察仍非核验事实；不授予公式计算资格，不推断多级表头或缺失值。

## 尚未达到目标的项目

1. 复杂多源、长程主题返回、多项同时替换、模糊实体及未见表达仍需独立未暴露会话集验收；现有规则支持不等于“各种复杂多轮都能搞定”。
2. 多工作进程的共享会话租约/CAS未实现；当前服务是单进程，SQLite持久化不等于分布式回合锁。
3. 扫描合并单元格、多级表头、无边框、跨页表格、透视照片与弯曲页面尚未全面实现；当前像素网格路径明确保守拒绝未覆盖结构。
4. 需要独立表格单元格金标与数值符号验证；现有局部OCR仅补观察，不能自行证明事实。
5. 校正/缩放/EXIF后的单元格到原图的完整逆变换未实现；已明确标记坐标框适用范围。
6. 严重模糊、遮挡、手写、多语言和损坏文件需更广泛真实样本；模糊金融页CER12.77%仍需改善。

本轮交付是可运行的实质改进，整体“顶级、全面真实场景”目标继续未完成。不将已有测试通过数作为赛题完成率。
