# 公共预算页的融合标签与金额拆分

新增 recover_merged_amount_pairs，集成到 RapidOCR 执行器。只针对同一OCR框中以货币金额结尾的文字，依据实际像素的空白列尝试分开裁剪，两侧三倍缩放后重新OCR；不按字符数量或文本比例猜测坐标。全文文字与原OCR框保持不变，拆分结果以非表格独立观察保存。

标签侧允许多个同一行、互不重叠的词框，文字仅连接实际识别词；完整标签与金额均需和原框内容一致（忽略空格与大小写）。冲突、坐标越界、零面积、低置信度或跨行词框拒绝。最多20次局部OCR、15秒软预算及每原框三个空白候选；单次模型调用不能被此软预算强制中断。

局部框保存裁剪SHA256、裁剪范围、原融合文字和识别来源，通过现有原图/PDF变换链映回来源。前端紫色虚线区分非表格条目；不把一致的两次OCR当成语义独立验证。

真实OHR-Bench预算原页（DUDE_4ead21606785b8a12a5382c99c98e38c.pdf，SHA256 b36413960ff43c854cdd8022721f27678de9733e2ac679eabd0ca1cb1813009a）五个融合小计均恢复：22.56、5.60、0.17、14.51m、10.83。上一轮39个金额未退步；所选44个金额44/44原页空间位置及金额顺序一致，不是整页完整率或官方成绩。财务页七金额仍7/7。

证据保留：runtime/public-merged-amount-pages-20261005.json 为单标签框规则下的中间结果（仅两项恢复）；runtime/merged-amount-crop-debug-20261005.json 揭示标签被分成词框、Commerce部分裁剪误识；最终 runtime/public-merged-amount-final-pages-20261005.json 和 runtime/public-merged-amount-reference-20261005.json。最后增加零面积拒绝没有重跑公开原件OCR，已有观察框均为非零面积，相关最终回归覆盖此代码。

验证：最终相关后端111 passed、1既有弃用警告；前端42 passed。测试包含像素空白边界、真实裁剪坐标回映、文本冲突、越界、调用/时间预算、无空白、失败保留及跨行词框反例。未重跑修改后全量，也未做真实浏览器点击。

仍缺：预算左侧FSA紧邻标签金额未配对、条目标签字母误识、完整机构归属/单位语义、跨页表格、透视校正、独立数值核验及结构化入库。OCR候选按观察数选优可能得到较差标签文字，全文保持独立选择，但候选标签质量仍需优化。整体目标未完成。
