# 嵌套衍生指标与多指标比较

比较 Agent 原来只允许衍生公式直接引用物理指标，导致正常编译执行的嵌套公式也无法保存比较快照。本轮将比较定义展开为完整依赖树，保持每个衍生节点的执行公式、单位、货币和除零规则；不按输出标签或内部ID判断指标相同。

依赖展开同时检查每层公式记录唯一匹配、未定义引用、循环、重复ID及物理/衍生ID冲突。深度上限16、展开节点预算512，防止异常依赖无限展开。未知/不一致记录不生成快照，也不会退化成按标签比较。

验证：比较与指标编译器67通过；增加独立SQLite参考后，最终嵌套和多指标专项7通过。实际查询两地区双倍客单价，值及差值与 `SUM(sales_amount)*2.0/COUNT(*)` 独立查询一致；来源查询由真实SQL编译器执行，非手工填入结果。多指标销售额/订单数分别按物理指标合同计算。反例包括循环、未知依赖、重复ID、缺失执行公式及中间节点单位变更。
