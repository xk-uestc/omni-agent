# 原件跨页表格比较正式接入（Round24）

本轮将原型接入 KnowledgeStore 普通问答与组合子问，不更改官方问题、参考答案、评分器或证据标准。仅用 gpt-6-luna / medium；凭据不进入源码、日志或此报告。

## 行为与核验

- 从检索命中的最多4份注册PDF重新提取重复表头、对齐列和全部候选行；不能将几何相似视为语义证明。
- 模型选择原始行及同一结果列，另一次独立审核读取完整候选来源、整页内容和竞争行，核对整问覆盖、地点、期间与左右主体。
- 同一文档、同一表链、两页明确出现且各页唯一的记录标识、同一字面单位是比较的前提。限值、星号、缺值、错列、单位冲突拒绝；不做单位换算或差值推测。
- Decimal 在服务器比较原始数值。答复保存原件SHA、候选注册表SHA、完整所选行、审核记录和计算结果；返回前重新读取原件重放。原件改变的 SourceIntegrityError 向上传递。
- 显式页码请求不自动扩大到跨页范围。全局 calculator_input_eligible 仍为 false；这一专用比较不能授权任意后续计算。
- `document.table.read` 与 `document.compare` 在 React 工具时间线分别展示实际反馈。首页与资料库原页都用服务器坐标映射分别标出主体和数值，先核验PNG哈希；换页清除旧标注。
