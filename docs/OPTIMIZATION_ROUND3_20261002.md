## 改动与验证边界

| 改动 | 解决的具体问题 | 保留的约束 |
|---|---|---|
| NL2SQL 角色拆分、Schema 来源绑定 | JOIN 键、过滤字段被当成统计指标；合法数值字段分组失败 | 字段与外键都来自实际 Schema，歧义不能被模型置信度绕过 |
| 有界结构修复 | 合法计划因内部 ID、标签或结构字段失败 | 最多一轮结构修复；重新执行语义、Schema、关联与编译校验，不修复语义错误来绕过约束 |
| 完整原生 PDF 区域 | 长人员表、同栏完整段落在生成上下文中被截断 | 从原件重抽，SHA、页、坐标、范围和预算可重放；文本上下文不授权数值计算 |
| 查询语言适配 | 中文向量模型对纯英文问题的分数压过更相关词法证据 | 声明模型支持语言，英文不受支持时使用词法；中文和受支持语言仍可混合检索 |
| 原文答案提取独立路径 | 首次事实生成拒答后，即使原文有字面答案也只能停在摘录 | quote-ID 定位、完整问题独立审查、原件重放；`claims=[]`，不得冒充已验证事实或用于物理量计算 |
| 百分数阈值比较 | 只返回阈值，未回答“是否满足” | 明确观测值与原文明示不等式，Decimal 程序比较，完整问题再次审查；复合、范围或缺失关系拒绝 |
| 首次响应时长绑定 | “首次响应时间”与“2小时内首次响应”被错误拒绝 | 局部事件关系和单位明确；“首次响应后关闭”“完成响应审核”、否定与禁止不授权 |
| 追问范围与图表百分比 | 追问校验后重写旁路、百分比方向/分母/舍入缺失 | 来源范围、显式基期、精确分数、完整操作数与舍入记录保留 |

## 数据来源与曝光程度

- Northwind 是公开示例数据库的社区移植版，16题由本项目编写，显式包含 Schema 字段；不是赛事官方题或官方 NL2SQL 榜单。
- OHR-Bench 是 OpenDataLab 的公开官方数据，当前使用的是资源约束小样本 PDF 原件。所谓“官方12题”指其中选取的12条，**不是赛题方提供12道标准题**。
- 第三轮新冻结批包含7份新 PDF、18题，类型分布为4/4/3/3/3/1，选择依据仅元数据。看过首测结果后，该批转为开发数据；最终重跑标记 `exposed_development_replay`，不能重称首次盲测。
- 金标、GT 和参考 SQL只用于评分，不进入检索、模型提示或业务数据。配对评分固定输入和分母，保留拒答、回退、API失败与退步。

最终固定版本结果、程序包验收与完整 D 盘备份以本文件后续验收记录为准。四核心长期目标仍进行中，尤其多模态新文档准确率远未证明90%达标；不换算比赛分数或获奖等级。
