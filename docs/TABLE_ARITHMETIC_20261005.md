# 表格观察金额的合计检查

## 实现

新增独立 `TableArithmeticAgent`，接入 `ScannedTableStructureAgent` 和跨页拼接预览。图片OCR、逐页PDF结构、确认后的跨页结果均可展示明细计算与总计差额。

只对第一列明确标注Total/Grand Total/合计/总计/总额、且位于唯一最后一行的观察表计算。检查每个金额列的全部明细、币种和总计，用Decimal精确求和；负金额与重复明细均保留，不去重、不补零。每项计算证据包含原行/列、原文、几何来源、明细数、计算合计、观察总计与有符号差额。

明确区分 `arithmetic_consistent`、`conflict`、`unavailable`、`not_applicable`。小计/累计/结转、多个或非末尾总计、缺失明细名称、合并数据格、空白/标点不明金额、混合币种或符号与币种身份混用、标题存在万元/thousands等倍率均停止相应计算。一个列冲突不会被另一列一致掩盖。2000格/400行预算，不以完整业务表或已核验OCR身份输出。

金额解析修复默认Decimal精度对长金额的舍入：200字符解析精度256、加总精度512；80位金额正负配对测试精确为0。`0.10+0.20=0.30`使用十进制，不容忍浮点误差。

前端直接显示观察值的合计一致/冲突、明细数量、计算总计、原表总计与差额，保留“只说明观察值算术关系”的提示。`cell_values_verified/table_completeness_verified`永远false：两处相互抵消的OCR错误或少行可能仍凑对总计，本Agent不能证明文字识别和业务范围正确。

## 验证

最终相关后端184 passed、1个既有Starlette/httpx警告；前端上下文/请求/会话/SVG/续表/金额63 passed，knowledge脚本语法通过。覆盖精确小数、负金额、重复标签、多金额列、缺失/歧义、多个总计、小计、单位倍率、币种、合并与长金额不舍入。

若恰好一格明细金额不明确、总计明确、其余明细与总计币种一致，附加 `review_candidate`：观察总计减其余明细得待核对金额；保留原文字/坐标、算式与未确认标记。状态仍unavailable，绝不据该候选改写OCR或宣称合计通过。多未知、总计未知、币种不一致不生成候选。
