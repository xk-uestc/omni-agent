# 多轮上下文展示打磨

本轮针对首页多轮澄清与上下文展示，不修改 SQL 执行或模型规划。

- 分开展示用户本次短句与实际采用的完整问题。
- 只在服务端核验的上下文中展示 replacements 的旧值→新值，区分时间、指标、分组与筛选条件；不从问题文字猜测继承字段。
- 缺时间范围与缺时间粒度分别提示，展示后端实际澄清原因，并说明补充后的下一步。
- 比较查询待补条件时提供“取消本次修改”，调用既有取消流程；其他澄清不提供未经支持的取消入口。
- 继续使用横线分隔与纯文本，无新增回答圆角卡片；所有动态内容通过 textContent 写入。
- 首页 CSS、上下文组件和 app 缓存版本统一更新。

验证：前端全部现有 Node 测试 32/32，通过 app.js 语法检查。服务 health 正常，首页 HTTP 返回新资源版本。未新增真实模型调用，未重跑后端全量回归，未进行真实浏览器点击验收。保留已有未提交修改，本轮没有提交或推送其他候选。
