## 实现

1. **复杂陌生 Schema**：按 SQLite 实际元数据区分 rowid alias 与可空主键；对 `_at/_on` 日期候选做整列执行快照探针，混合 T／空格不直接按文本排序；分组平均阈值沿用真实前阶段总体及原生 NULL 语义。SQL 仍需只读 AST、来源与独立整题审核。
2. **复杂文档**：恢复真实旋转字词的显示坐标；按显式货币列头、有界空白间隔和唯一金额列隔离同页表格与图表。标签里的 Top 20 不再冒充第二数据列。金额占比使用精确有理数，可按用户明确要求显示 0～6 位小数，保留舍入标记；绝对差与有向差分开。跨表、不同单位/期间、缺失信息、多子问不完整的情况继续拒绝。
3. **连续会话**：修复显式时长事件标签“首次响应时间要求”的事实绑定，保留模态/事件/单位守卫；评测增加第 2/5 轮重建全部生产对象，从 SQLite 恢复完整历史后继续追问和失败恢复。
