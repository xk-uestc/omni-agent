# 问数演示数据库

主问数源为 `demo_sales.sqlite`，采用确定性生成的合成数据，不代表真实企业经营数据。服务启动时只对默认演示库执行幂等扩展；显式配置的业务库不受影响。

数据覆盖 2022-01 至 2026-12、8 个区域、44 个产品、248 个客户和 48 名销售顾问，共 10 张表、39,640 条记录：

| 表 | 记录数 | 内容 |
|---|---:|---|
| `sales_orders` | 12,012 | 订单、收入、优惠、毛利、渠道、状态和配送 |
| `customers` | 248 | 客户等级、行业、区域、获客渠道和年度价值 |
| `products` | 44 | 产品品类、品牌、标价、成本和上市时间 |
| `regions` | 8 | 区域与代表城市 |
| `sales_reps` | 48 | 销售人员、团队和区域 |
| `support_tickets` | 4,000 | 售后状态、优先级、问题类型、时长和满意度 |
| `inventory_snapshots` | 21,120 | 月度区域产品库存、在途量、安全库存和库存金额 |
| `marketing_campaigns` | 480 | 月度区域营销预算、曝光、点击、转化和归因销售额 |
| `sales_targets` | 480 | 月度区域销售额与订单目标 |
| `sales_returns` | 1,200 | 关联订单的退货原因、状态、日期和退款金额 |

当前网页接入两类数据源：上述问数数据库，以及 `knowledge.sqlite` 文档资料库。左侧栏显示各自的表/记录规模或文档/片段数量；评测和压力测试 SQLite 文件不属于线上可问数据源。
