# 六轮与随机追问修复验收（2026-10-07）

## 实际结果

- 公网地址：https://raysource.cloud/demo/
- 原六轮浏览器演示：6/6 返回正确；已保存服务端会话执行记录。
- 两个随机种子、6 个独立会话、每会话 5 轮：30/30 公网请求通过。
- 每轮独立只读 SQLite 计算期望值，同时核验 SQL 计划的地区、年份范围、指标字段、聚合函数。
- 本地相关回归：151 passed；前端 JavaScript 语法和 diff 空白检查通过。
- 8031 服务已重启加载修复，公网页面返回 HTTP 200，watchdog 运行中。

## 修改

1. 根据明确指标的事实表定位地区值，解决丰富样例中多个表包含同名地区导致的歧义；同表不同字段的歧义仍保留。
2. 裸地区、裸年份、再看一下、改看、看看等短句能沿用上轮已执行查询，替换指定槽位。
3. 兼容旧单指标历史没有 metrics 表信息的情况，从上轮完整问题恢复指标表。
4. 指标替换校验使用相同的对话前缀规范化，保留未提及的约束并重新核验完整查询。
5. 已核验追问保持 SQL 路由；模型计划不能丢弃地区筛选或用错误地区字符串绕过独立校验。
6. 六轮演示创建独立会话并开启上下文，避免重复点击；失败、澄清或切换会话时中止后续轮次。

## 范围与限制

这是项目合成销售数据库的追问验收，不代表通用问数准确率或全部赛题能力。公开请求过程中未修改实际数据库；数据库版本变化仍会拒绝历史继承。一些查询仍走模型审核或生成路径，本轮没有承诺整体速度问题已解决。

30 个真实请求平均耗时 11.01 秒，中位数 10.84 秒，范围 4.38–21.11 秒（两个会话并发，包含公网传输）。
