# 显式主题返回与扫描合并单元格

## 本轮实现

SQL上下文支持明确的引用语句 `回到上一次SQL查询，那华南呢`。仅在保留历史窗口内寻找最近SQL轮次，校验执行记录的问题、参数、SQL、来源版本及摘要，再经过原有范围改写与再规划流程；模型不自行选择旧主题。失败的最近SQL不会被默默跳过。用户明确指定 `回到上一次成功的SQL查询` 时才查找最近成功记录。历史已经过期、引用未执行或无法核验改写时继续澄清。无显式引用的普通追问维持原来的最近轮次规则。

扫描规则网格由完整线条检测扩展为局部边界验证：缺失边界按相邻原子格组成矩形合并区域，记录 `rowspan`、`colspan` 和覆盖格锚点。表头内容可以跨越已确认的合并区域绑定OCR框；覆盖格不重复识别。中间强度的破损线、不闭合外框、非矩形合并以及合并区域中残留的内部隔线不能被猜为单元格。表头语义仍不推断，OCR数值依然是观察值，不自动授予计算核验资格。

- SQL上下文及集成回归：71 passed（22.04秒）。覆盖文档插话后回SQL、失败轮次不跳过、明确回成功查询、引用超出历史窗口。
- 规则扫描网格回归：8 passed。覆盖横向表头合并、纵向合并、覆盖格不重复OCR、跨真实边界框不猜测、破损及非矩形合并拒绝。
