# 原件表格筛选与完整投影（Round25—26，待最终回归）

目标对应赛题的异构来源定位、条件理解、鲁棒性与全链路解释。模型只提出本次问题的表链、字面筛选与输出字段；服务器遍历所有候选行，无任意limit或数字运算。独立审核读取完整页文、所有竞争行及来源，核对条件与清单，不把几何当语义证明。

## 当前实现

- 字面相等和转义后的词边界匹配，例如METHOD_A不能误匹配METHOD_AB。投影必须逐个覆盖全部匹配行与所需字段；每个原文字面和位置绑定到指定原件行。
- 相同字段仅在所有匹配行均相同时提取为共同字段，其他字段保留行关联。空白、限值、单位或星号不被推断、换算或填补。
- 保存原件SHA、候选行注册表SHA、投影与审核清单；交付前重读原件重放。全局calculator_input_eligible=false。
- 固定要求数量与完整清单冲突时明确请求澄清，不能任意挑子集。Round25真实测试暴露协议失败后的回退缺口；Round26已关闭该回退并保留失败证据，最终回归通过后已部署。
- 原页多个输出字段独立高亮；工具时间线分别显示读取与筛选。
- 修复组合组件缺少native_page_contexts的问题。后续整问复核移除重复几何／重复页文序列化，保留每一行、字段字面及完整页文；原5000字符/页、12000页文总量及60000组合包预算没有提高。真实原件比较＋筛选组合测试已到达整问复核，未替换原件重放函数。
